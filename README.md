One sentence, 198 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun — describe the idea in plain words, the agent builds it, free to try, no code, and you only keep it if you love it. Written by `main.ts` to `/output/entry.txt` for make.fun's "A Day of One-Line Pitches" bounty.

## Run it

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (creating `/output` if needed). Deterministic: no network, no randomness, no timestamps — the same bytes on every run.
